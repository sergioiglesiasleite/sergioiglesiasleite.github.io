# Portfolio de Sergio Iglesias Leite

Portfolio profesional orientado a soporte técnico de producto, onboarding, implantación y análisis funcional junior. Presenta Nutreefit, Globoom, PC Assembly Field Guide y Cat-O.

## Cat-O

Mascota virtual para iPhone inspirada en Gofre: cuidados, tres estancias, gestos, cuatro minijuegos y personalización. Experiencia familiar sin anuncios ni penalización por ausencias, con un pack cosmético opcional tras control para padres.

Mi aportación es la dirección de producto, la definición de requisitos y decisiones de diseño, el QA en iPhone y la preparación de TestFlight y del envío a Apple. Desarrollo asistido por Codex y Claude; arte generado con Codex/ChatGPT.

**Estado registrado el 03/10/2026:** versión 1.0 (build 8) y pack «Invierno acogedor» enviados a revisión de Apple. Publicación manual tras aprobación; todavía sin disponibilidad pública en App Store acreditada. Una corrección posterior a la build 8 queda para otra actualización.
